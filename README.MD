## What I Learned

 1. Hapi Plugin and data validation using JOI
 2. Postgres SQL and deploying to Amazon RDS
 3. Deploying to Amazon EC2
 4. Restful API
 5. Authentication and Authorization using JWT
 6. Database normalization
 7. Message Broker using RabbitMQ and Amazon MQ
 8. Storage using Amazon S3
 9. Caching using Redis and deploying using Amazon ElastiCache
